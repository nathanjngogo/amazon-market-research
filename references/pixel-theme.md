# 看板像素风主题规范（BW1 · 报纸灰阶 — 唯一钦定主题）

> 本规范为宪法级交付样式：所有 HTML 市场调研看板必须逐条实现本文件的 token 与区块结构。禁止临场改用其他配色/圆角/阴影；如需演进主题，必须修订本文件并升版本号，禁止只改单次产物。

## 0. 设计基因

- 风格 = 像素风「报纸灰阶」：硬边框、零圆角、偏移硬阴影、5 级灰、等宽字体、扫描方块光标。
- 渲染基线：`image-rendering: pixelated`；一切 `border-radius: 0`（用通配规则强制）。
- 字库：`"Courier New","SimSun",monospace` 通配栈，**零外部字库、零 CDN**（符合全局思源黑体/本地化约定的像素风例外：本主题为等宽 ASCII 美学，SimSun 保证 CJK 本地可渲染）。

## 1. 色板 token（CSS 变量，逐字使用）

```css
:root{
  --bg:#d9d9d9;   /* 页面底 */
  --paper:#f5f5f5;/* 看板纸面 */
  --card:#ffffff; /* 卡片/表体 */
  --alt:#e8e8e8;  /* 次级底纹/斑马行 */
  --ink:#111111;  /* 主墨色：边框、标题底、强调 */
  --mid:#616161;  /* 中灰：次级标题底、说明字 */
  --line:#9e9e9e; /* 浅线：次级边框 */
}
```

纪律：只允许这 7 色。四象限重点格用 `--ink` 反白；次重点用 `--line` 底。状态色不用彩色，用「实心 ink / 斜纹 / 空心」三档表达强中弱。

## 2. 区块结构（固定顺序）

1. **头版 hd**：`--ink` 底反白标题，`▓▒░ … ░▒▓` 装饰包裹；副行小字 `--line` 打印 数据源/口径版本/站点，尾部闪烁光标 `█`（`steps(2)` 动画）。
2. **KPI 条**：4 列网格，`--card` 底 3px 实线 `--ink` 边框；偶数格 `--alt` 底。
3. **九站流程条**：每站一格；已过站 = `--ink` 底反白，未到站 = `--alt` 底 `--line` 边 + `--mid` 字。
4. **数据区**（每节一节，可重复）：`.sec` 白卡 + `--ink` 3px 边框；节头 `h2` = `--mid` 底反白 12px 字，`letter-spacing:2px`。
   - 条形图：`.bar` 高 16px、2px ink 边框，填充 = ink 斜纹 `repeating-linear-gradient(90deg,ink 0 6px,#3a3a3a 6px 8px)`；行栅格 `104px | 1fr | 60px`（名 | 条 | 百分比）。
   - 表格：th ink 底反白；td 2px `--line` 边，斑马行 `--alt`。
   - 四象限：固定 2×2；主攻格 ink 反白，机会格 `--line` 底，其余白/alt。
5. **口径声明栏 cal**（强制，宪法第 6 条）：`--alt` 底 ink 3px 边框；首行加粗「【口径声明·宪法层】」；逐条打印所用口径 + 行尾 `本会话微调：无` 或微调登记列表。

## 3. 通用规则

- 外框：`.shell` = `--paper` 底 5px ink 边 + `8px 8px 0 --line` 硬阴影；max-width 960px 居中。
- 全部间距为 4px 的整数倍（像素对齐）。
- 数字/金额右对齐用等宽天然对齐；中文标签左对齐。
- 图表仍走 ECharts 白名单（本地内嵌），但 chart option 的颜色必须取本 7 色 token，像素字体 `fontFamily` 同步 Courier 栈，`animation:false`。
- 打印友好：不得用背景图依赖网络；`@media print` 下隐藏闪烁动画即可，其余原样。
